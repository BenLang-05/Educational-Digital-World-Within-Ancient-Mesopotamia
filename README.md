# Educational Digital World Within Ancient Mesopotamia
A Unity-based educational virtual world developed as part of my final-year Computer Science dissertation. 
The project explores how interactive digital environments can be used to teach users about the history and culture of Ancient Mesopotamia. 

## Overview
Ancient Mesopotamia is often referred to as the "cradle of civilisation", yet it remains largely underrepresented in both education and digital media.
This project was created to provide an engaging way for users to learn about the civilisation through exploration, interaction, and game-based learning. 

## The experience consists of:

A virtual museum containing Mesopotamian artefacts and information displays. <br>
A reconstructed Mesopotamian city environment for free exploration.<br>
Interactive exhibits and learning content.<br>
A quiz system designed to assess user understanding of the topic. <br>

## Technologies Used
Unity,
C#,
Blender

## Features
First-person exploration,
Interactive museum exhibits,
Virtual Mesopotamian city,
Scene transitions between environments,
Educational information boards,
Quiz-based learning system,
Custom 3D models created in Blender 

## Evaluation
The project was tested with 10 participants to evaluate usability, immersion, and educational effectiveness. 
Results showed positive engagement and increased understanding of Ancient Mesopotamian history among users. 

## Dissertation
This project was developed for my BSc (Hons) Computer Science dissertation at Keele University and received a First-Class classification as part of my degree.
